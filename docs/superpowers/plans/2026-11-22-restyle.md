# Restyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Replace the paper/rust theme and the 7-column ledger table with the concrete-wall /
punched-tag / label-tape system, add the About block, skills and three projects.

**Architecture:** Same stdlib generator. `style.py` (palette + CSS), `render.py` (markup),
`content/` (ledger + site.json), `verify/verify.py` (checks). Validator rules unchanged except
`PROJECTS`.

**Tech Stack:** Python 3.12 stdlib; bundled Barlow Condensed TTF (OFL).

**Spec:** `docs/superpowers/specs/2026-11-22-restyle-design.md`

## Global Constraints
- Zero dependencies, zero third-party requests, every page works with JS off.
- Colour encodes family only; every state keeps a text label and a shape.
- No teammate names, employers, grades, location; no invented numbers.
- WCAG AA: text 4.5:1, non-text 3:1, both schemes.
- No gradients, no non-zero border-radius, no backdrop-filter.

## Review Focus
1. Phone width (375px): tags, tape and count strip must not overflow horizontally.
2. JS off: the ledger shows every tag; the filter form stays hidden.
3. Dark mode: text on the wall (headings, counts, nav) must use wall-ink, not tag ink.
4. Deep links: `ledger/#<id>` must land on the tag for every public id.
5. A family with zero entries in a project renders nothing, not an empty heading.
