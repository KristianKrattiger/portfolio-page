# Colophon

How this site is built, hosted, verified, and what context it was built from. (Kept in the repository; the published `/colophon/` web page was replaced by `/ai/` for AI disclosure.)

## Build

- One ledger file (`content/ledger.yaml`) is the sole source of factual entries.
- A Python 3 standard-library script (`build.py`) validates it and writes deterministic static HTML, CSS, fonts, and `ledger.json` into `dist/`.
- The build fails non-zero and writes nothing if:
  - a `MEASURED` entry lacks metric, value, denominator, dataset, synthetic flag, system, date, or evidence;
  - a `KILLED` entry lacks `kill_criterion`;
  - a `BLOCKED` entry lacks `blocked_by`;
  - a `LINKED` entry lacks a tier-1 evidence item with path, branch, and SHA;
  - any entry lacks `as_of` or `does_not_show`.
- `STALE` is computed at build time (`as_of` older than 90 days before `PORTFOLIO_BUILD_DATE`).
- Zero third-party runtime dependencies, zero analytics, zero cookies. Every page works without JavaScript (the single inline filter script on `/ledger/` duplicates the pre-rendered `/ledger/<facet>/<value>/` pages).
- Type: Barlow Condensed (SIL Open Font License, bundled under `assets/fonts/` and copied to `dist/fonts/`) for headings and claims, platform serif for prose, platform monospace for data.
- Colour marks epistemic family only: black tape = done, red tape = failed, yellow tape on manila = unfinished.

## Hosting

- Production: served from a headless EndeavourOS Beelink SER mini PC (`reef`) using Caddy (read-only static container with atomic release symlink swaps) behind an outbound-only Cloudflare Tunnel (`krattiger.dev`). See `infra/README.md`.
- Local development: `python -m http.server` bound to `127.0.0.1:8787` (`./run.sh` or `service/install-service.ps1`).

## Context Walked & Verification

- Walk metadata and scope: `content/walk.json` and `SOURCES.md`.
- Latest verification results: `content/site_checks.json` (generated by `python verify/verify.py`, with `--skip-local-repos` available for CI/server runs).
- Decisions made without asking during initial assembly: `ASSUMPTIONS.md`.
- Remaining author review items: `NEEDS_AUTHOR.md`.
